# AzL Sonar — research (S-1, S-2, S-3)

Research for plan tasks S-1, S-2 and S-3 ([plan](plan.md)), checked against the contract in [design](design.md). Written 10 Oct 2026.

**Rules used.** Microsoft Learn is the only source. Azure Local pages are read at `view=azloc-2609`. Every row cites the Learn page it comes from. When Learn does not state something, the row says **Not on Learn** and the item stays unverified until the lab confirms it. The **Verified live 10 Oct 2026** column is left empty for the owner to fill in from the `nic26-clus01` lab.

## 0. What this changes in the design

These are the findings that conflict with [design.md](design.md) or add a risk to it. Each one is explained further down.

| # | Finding | Effect on the design | Source |
|---|---|---|---|
| D1 | Learn's template reference lists `Microsoft.AzureStackHCI/edgeMachines` and `edgeMachines/jobs` only from **2025-12-01-preview** onward (2025-12-01-preview, 2026-02-15-preview, 2026-03-01-preview, 2026-04-01-preview, 2026-05-01-preview, 2026-10-01, 2026-10-15-preview). There is no 2025-09-15-preview page. Microsoft's own retry script for OS provisioning calls `edgeMachines` with `api-version=2025-12-01-preview`. | Poller step 3 (`edgeMachines?api-version=2025-09-15-preview`) will probably be rejected. Use a separate edge-machine api-version, defaulting to `2025-12-01-preview`. | https://learn.microsoft.com/azure/templates/microsoft.azurestackhci/edgemachines ; https://learn.microsoft.com/azure/azure-local/deploy/troubleshoot-simplified-machine-provisioning?view=azloc-2609 |
| D2 | Learn documents only three step `status` values: `'Error', 'Success', 'InProgress'`. `EceActionStatus.status` is an untyped string with no list of values. | `NotStarted`/`Not Started`, `Failed` and `Skipped` in the design come from what the lab saw, not from Learn. Keep the normaliser tolerant and send any unknown value to `notstarted`, never to `error`. | https://learn.microsoft.com/javascript/api/@azure/arm-azurestackhci/deploymentstep?view=azure-node-preview |
| D3 | Learn has no REST page for the read-only `reportedProperties` at 2025-09-15-preview. The Learn REST reference shows api-version 2024-04-01, and the template reference leaves out read-only properties. The newest preview SDK models have the same shape as 2024-04-01. | Low risk, but the 2025-09-15-preview shape is only inferred. Confirm it in the lab. | https://learn.microsoft.com/rest/api/stackhci/deployment-settings/get ; https://learn.microsoft.com/azure/templates/microsoft.azurestackhci/2025-09-15-preview/clusters/deploymentsettings |
| D4 | The edge machine lifecycle seen in the lab (`Creating → AwaitingConnection → Provisioning → ReadyForOs → InstallingOs → Provisioned`) does not appear on Learn. Learn's `machineState` enum is different: `Created, Preparing, Registering, Transitioning, Purposed, Unpurposed, Resetting, Updating, Failed`. `provisioningState` uses the generic HCI enum. | Read `machineState`, `provisioningState` and the ProvisionOs job together, and treat any value as a free string. Find out in the lab which field held the lab values. | https://learn.microsoft.com/dotnet/api/azure.resourcemanager.hci.models.edgemachinestate?view=azure-dotnet-preview |
| D5 | Learn does not name the deployment log files under `C:\CloudDeployment\Logs`. It names only the Environment Checker log and report written there during deployment, and the upgrade logs (`FullCloudUpgrade.*.log`, and `C:\MASLogs\LcmEceLiteLogs\InvokeCloudUpgradeEnvironmentChecker.*.log`). | The default `logs.paths` is reasonable, but Learn does not guarantee the file names or the rotation. Tail by folder, which the design already does. | https://learn.microsoft.com/azure/azure-local/manage/use-environment-checker?view=azloc-2609 ; https://learn.microsoft.com/azure/azure-local/upgrade/troubleshoot-upgrade-to-23h2?view=azloc-2609 |
| D6 | Learn does not state the file permissions on `C:\CloudDeployment\Logs` or `C:\MASLogs`. "Members of local Administrators can read them" is inferred, not documented. | Every row about which account can read the logs is unverified until the lab confirms it. | — |
| D7 | After deployment, the built-in Administrator (RID 500) is renamed **ASBuiltInAdmin** and RDP is turned off. | If the credential uses the built-in `Administrator` name, it stops working once deployment finishes. Sonar must say so in its guidance. | https://learn.microsoft.com/azure/azure-local/concepts/security-features?view=azloc-2609#local-built-in-user-accounts ; https://learn.microsoft.com/azure/azure-local/deploy/deploy-via-portal?view=azloc-2609#post-deployment-tasks |
| D8 | An Arc run command is an Azure **write**: a `PUT .../machines/{m}/runCommands/{name}` that needs `Microsoft.HybridCompute/machines/runCommands/write`. Arc SSH can also `PUT` the HybridConnectivity endpoint and its service configuration. | Using either one breaks design goal 5 ("never changes Azure"). Keep both off by default and only turn them on when the user explicitly opts in. | https://learn.microsoft.com/azure/azure-arc/servers/run-command ; https://learn.microsoft.com/azure/azure-arc/servers/ssh-arc-overview |
| D9 | When the workstation is in a workgroup, or connects by IP address, WinRM uses NTLM and needs the target in `TrustedHosts` or HTTPS. For a local account that isn't the built-in Administrator, a Windows Admin Center page says `LocalAccountTokenFilterPolicy=1` may be needed on the target. Learn says nothing about whether Azure Local sets it. | Local Identity nodes, and AD nodes before they're joined to the domain, can refuse remoting with the deployment local admin even when TrustedHosts is correct. Sonar should report "access denied" separately from "TrustedHosts". | https://learn.microsoft.com/powershell/module/microsoft.powershell.core/about/about_remote_troubleshooting?view=powershell-7.6 ; https://learn.microsoft.com/windows-server/manage/windows-admin-center/support/troubleshooting#using-windows-admin-center-in-a-workgroup |

## S-3 — Ways to reach the logs

| Method | What it needs | Limits and security | Source | Verified live 10 Oct 2026 |
|---|---|---|---|---|
